# 🎓 Student Expense Tracker

A simple and responsive web application designed to help students track, manage and analyze their daily expenses.

## 📌 About the Project

The Student Expense Tracker allows users to record their daily expenses by entering the expense name, amount, category and date.

The application provides automatic spending calculations, search and category filtering, expense management and a category-wise spending summary.

Expense data is stored using browser Local Storage, allowing the information to remain available even after refreshing the page.

## ✨ Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Search expenses
- Filter expenses by category
- Automatic total spending calculation
- Track highest expense
- Display total number of expenses
- Category-wise spending summary
- Local Storage data persistence
- Responsive design
- Modern and user-friendly interface
